# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-16

### Added
- Multi-page crawl in a real Chrome browser, seeded from the sitemap
- Google Lighthouse on mobile, desktop or both, with Core Web Vitals and speed opportunities
- WCAG 2.2 AA accessibility testing with axe-core on every page
- Link checker for every internal and external link, plus broken files and JavaScript errors
- Site-wide checks: SSL certificate, HTTPS redirect, security headers, robots.txt and XML sitemap
- Optional real-visitor Core Web Vitals from the Chrome UX Report (free Google API key)
- Rules engine with 50+ checks, severities, effort estimates, plain-English fixes and A–F grades
- Built-in written summary, quick wins and draft client email
- Designed PDF report, interactive HTML export and four CSV exports
- Before/after comparison with the previous audit of the same site
- Landing page, New audit page, History page with per-site trends, and live progress
- Light, dark and system themes; responsive layout from 320 px phones to desktop
- Vercel deployment with serverless Chromium, Vercel Blob storage and streamed progress
- Open access without passwords: per-browser history, shareable report links and rate limiting
